# Support

Rirei is pre-release software maintained on a best-effort basis.

- Use GitHub Discussions or issues for usage questions and reproducible bugs.
- Use private vulnerability reporting for security issues.
- Include the Rirei version, macOS/Node versions, provider CLI and version, and sanitized steps.
- Do not attach `.relay/` state, checkpoints, provider transcripts, terminal output, credentials,
  or approval payloads without reviewing and redacting them first.

Provider authentication, billing, subscriptions, limits, and service availability remain the
responsibility of the corresponding provider.
