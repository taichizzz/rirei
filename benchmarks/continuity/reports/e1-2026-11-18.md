## Helper-routing finding

No receiver called `context inspect`, `find`, `read`, `batch`, or the selected context helper.
All four Codex runs issued bare `relay message peers` and `relay message inbox` queries, eight
queries total, and received empty coordination results.

The benchmark's explicit `./.benchmark-tools/relay` helper rejects those commands. An offline
replay confirmed that `/bin/zsh -lc` resolves the installed `relay` instead of the helper prepended
to the parent process's PATH. Thus the prompt's bare-command alias claim did not hold in the
native login shell. The explicit helper path was available and passed the offline rehearsal.

The inline handoff comparison remains observed, but **this run does not qualify native targeted
retrieval or per-arm helper routing**. Future preparation should remove the PATH assumption,
identify the explicit versioned helper path in instructions, and test it through the actual
provider shell before spending another live budget. The captured run is preserved as executed.
